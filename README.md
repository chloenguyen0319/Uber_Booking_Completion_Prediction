# 🚗 Uber Premium Booking Completion Prediction

## 📊 Overview

This repository contains the complete analysis and deliverables for our MGT 256 project evaluating the efficacy of Uber Premium booking completion. The project investigates factors influencing booking completion rates and provides actionable insights through comprehensive business and technical analyses.

## 📝 Project Description

This study examines Uber Premium booking completion patterns using statistical modeling and data analysis techniques. The project emphasizes the need for an enhanced data strategy to better understand and predict customer booking behavior.

## 📁 Repository Contents

```
├── source.Rmd              # R Markdown source code with complete analysis
├── technical_report.pdf    # Technical report detailing implementation in R
├── business_report.pdf     # Business-oriented report with findings and recommendations
└── README.md              # This file
```

## 📄 Reports

### 💼 Business Report
The **business_report.pdf** provides:
- Executive summary of findings
- Business implications and recommendations
- Strategic insights for improving booking completion rates
- Non-technical presentation suitable for stakeholders

### 🔬 Technical Report
The **technical_report.pdf** includes:
- Detailed methodology and statistical approaches
- Implementation specifics in R
- Model validation and performance metrics
- Technical appendices and code documentation

## 🚀 Getting Started

### ✅ Prerequisites
- R (version 3.6 or higher recommended)
- RStudio (optional, but recommended)
- Required R packages (see source.Rmd for dependencies)

### ▶️ Running the Analysis
1. Clone this repository
2. Open `source.Rmd` in RStudio
3. Install required packages as specified in the source file
4. Knit the document to reproduce the analysis
